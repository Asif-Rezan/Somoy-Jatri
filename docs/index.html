Somoy Jatri Automation

Somoy Jatri Automation is an owner-operated tool that prepares videos and uploads them to the Somoy Jatri YouTube channel. It uses Google authorization to read the selected YouTube channel, upload videos privately, and work with files in an app-authorized Google Drive folder.

The channel features English documentaries about Islamic history and sourced hadith lessons with AI-assisted narration and illustrations.

There is no public sign-up or service for other users. The operator controls each authorization and can revoke it in their Google Account.
