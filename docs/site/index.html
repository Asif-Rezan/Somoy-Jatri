Somoy Jatri Automation

A private publishing tool for original Bangla historical reconstruction videos.

The channel owner uses this application to prepare narration, scene illustrations, captions and audio, store production checkpoints in a dedicated Google Drive folder, and upload reviewed videos to the authorized YouTube channel.

Google account access

Google authorization is used for the owner's production workflow. Drive access is limited to files created by or explicitly shared with the application. YouTube access supports video and thumbnail uploads and read-only checks of channel identity and processing status.

This tool is operated for the Somoy Jatri channel. It is not a public sign-up service.
