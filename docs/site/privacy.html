Somoy Jatri Automation

Privacy policy

Effective October 18, 2026

Somoy Jatri Automation is operated by Asif Rezan for the Somoy Jatri — Time Travel Vlogs channel. This policy describes the application implemented in the linked source repository.

Information used

The application uses Google OAuth credentials, the authorized Drive account email, a dedicated Drive folder identifier, and YouTube channel and video identifiers, titles, visibility and processing status. It stores scripts, research, narration, illustrations, captions, video files and production checkpoints.

Purpose and permissions

Drive access uses the drive.file scope for app-created or explicitly app-authorized files. It supports private storage, recovery and cleanup. YouTube upload permission supports video and thumbnail uploads; read-only permission verifies the intended channel and upload status. The application does not request Gmail or contact access.

Storage and processing

OAuth credentials are stored locally with owner-only file permissions during authorization and as encrypted GitHub Actions secrets for hosted execution. Production files and upload checkpoints are stored in the dedicated owner-controlled Drive folder. Workflows may also save media and manifests as GitHub Actions artifacts with configured retention periods. Repository collaborators with appropriate access can operate these workflows; the owner is responsible for repository and artifact access settings.

Groq is used to generate scripts and review scene plans. Google account credentials and Google account/channel metadata are not supplied to Groq by the application. The owner should not include private personal information in research or script inputs.

Use and sharing

Google user data is used for the authorized production and publishing workflow, not for advertising, sale or training general-purpose AI models. Transfers of Google user data are limited to the application’s operation through Google services and the owner-authorized GitHub Actions environment. Somoy Jatri Automation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The owner controls Drive files, local files, GitHub secrets and artifact retention. Checkpoints are retained for recovery until the owner removes them or approved cleanup applies. Access can be revoked from Google Account connections. Revoking access does not delete existing files: remove those separately in Drive, GitHub or the local workspace. YouTube videos remain under the channel owner's control.

Contact and changes

For access, deletion or policy questions, contact asifrezan.office@gmail.com. Changes will be recorded on this page with an updated effective date.
